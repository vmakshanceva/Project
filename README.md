## Идея компании

Сеть студий звукозаписи в крупных городах России для музыкантов с возможностью почасовой аренды. Студии оснащены необходимым оборудованием для записи музыкальных композиций в популярных жанрах современной сцены.

## Разделение обязанностей

- Макшанцева Варвара - Анализ географии и загрузки (в каких районах открывать студии, где дефицит, где высокая проходимость музыкантов)
-  Липский Андрей - Анализ конкурентов (кто уже сдаёт студии, их цены, оборудование, отзывы, наше преимущество)
